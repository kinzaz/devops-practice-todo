# Простой Todo

Три части: **React (UI) → FastAPI (сервер) → SQLite (база данных)**.
Добавление, выполнение и удаление задач. Данные сохраняются на сервере в файле `app/todo.db` и переживают перезапуск. SQLite — полноценная встроенная база данных; отдельный процесс для неё запускать не нужно.

Сейчас мы учимся запускать приложение локально. Docker, CI и мониторинг добавим позже.

## Что установить

- Python 3.13 или новее.
- Node.js 20.19 или новее и npm.

## 1. Запустить сервер

Открой терминал в папке проекта:

```sh
cd /Users/kinzaz/Documents/devOps
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Оставь терминал открытым. Сервер слушает http://127.0.0.1:8000.
Документация API: http://127.0.0.1:8000/docs. На корневом адресе страницы нет: UI запускается отдельно.

## 2. Запустить UI

Открой второй терминал:

```sh
cd /Users/kinzaz/Documents/devOps/frontend
npm install
npm run dev
```

Открой http://127.0.0.1:5173. Добавь задачу, отметь выполненной, обнови страницу: задача сохранится.

Оба терминала должны работать одновременно. Для остановки нажми Ctrl+C в каждом. При следующем запуске устанавливать зависимости заново не нужно.

## Как это связано

Браузер показывает React-приложение на порту 5173. React отправляет запросы на `/api/todos`. Сервер разработки UI перенаправляет их в FastAPI на порт 8000. FastAPI читает и записывает задачи в SQLite. Браузер напрямую к базе не подключается.

| Метод | Адрес | Действие |
|---|---|---|
| GET | /api/todos | Получить задачи |
| POST | /api/todos | Создать: `{"title":"Изучить запуск"}` |
| PATCH | /api/todos/1 | Изменить состояние: `{"done":true}` |
| DELETE | /api/todos/1 | Удалить задачу |

## Первое занятие DevOps

1. Запусти сервер и UI вручную по инструкции.
2. Создай задачу и обнови страницу.
3. Останови сервер и попробуй добавить задачу. Посмотри ошибку в интерфейсе и запрос во вкладке Network инструментов разработчика браузера.
4. Запусти сервер снова, нажми «Повторить» и проверь, что задачи остались.
5. Найди файл `app/todo.db`. Это база с твоими задачами: сохрани его копию при остановленном сервере.

Цель первого занятия: понимать, какие части приложения работают, как их запустить и где хранятся данные.

## Необязательные проверки для разработки

Из корня проекта с активированным Python-окружением:

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Проверка сборки UI из папки frontend: `npm run build`. Сборка создаёт файлы в `frontend/dist`; для текущих занятий используй `npm run dev`.

Приложение предназначено для локального обучения: учётных записей и авторизации пока нет.
